# Support

acp-gateway is maintained by one person. This is what that person can keep:

- **Questions and bugs:** open a GitHub issue using the templates. Responses are best-effort, with no
  guaranteed response time.
- **Security reports:** follow [SECURITY.md](SECURITY.md); never a public issue.
- **Versions:** the project does not publish releases. Only the latest commit on `main` is supported;
  fixes land there.
- **Self-hosting:** the README's "Self-hosting" section is the supported path. Operating someone
  else's deployment is out of scope.
